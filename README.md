# Проект модуля 14
## Инструкция по установке
1. клонирование репозитория 
``` powershell
git clone git@github.com:shk1t/skypro_m14.git
```
2. проверка poetry
``` powershell
poetry --version
```
3. установка зависимостей проекта
``` powershell
poetry install
```
4. активация окружения

`если установлен shell`
``` powershell
poetry shell
```
`если не установлен`
``` powershell
poetry env activate
```
